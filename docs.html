General Usage

This Ruby Sandbox runs entirely in your browser using Ruby WASM. You can write standard Ruby code in the editor on the left and see the output on the right.

  • Use puts or print to output text.
  • Use gets to read input from a prompt.

Example:

puts "What is your name?"
name = gets.chomp
puts "Hello, #{name}!"

Turtle graphics for Ruby

Introduction

Turtle graphics is an implementation of the popular geometric drawing tools originally introduced in Logo. It provides an educational framework for simple graphics applications, providing instant, visible feedback to learners.

In this Ruby Sandbox environment, Turtle graphics is powered by Ruby WASM and draws directly onto an HTML5 Canvas.

Get started

Imagine a robotic turtle starting at [0, 0] in the x-y plane. After requiring the library and creating a turtle object, give it the command turtle.forward(15), and it moves 15 pixels in the direction it is facing, drawing a line as it moves. Give it the command turtle.right(25), and it rotates in-place 25 degrees clockwise.

require 'turtle'

turtle = Turtle.new
turtle.forward(15)
turtle.right(25)

Tutorial

New users should start here. In this tutorial we'll explore some of the basics of turtle drawing.

Starting a turtle environment

In your Sandbox, simply require the library and instantiate a new Turtle object:

require 'turtle'
turtle = Turtle.new

Basic drawing

Send the turtle forward 100 steps:

turtle.forward(100)

You should see a line drawn by the turtle, heading East. Change the direction of the turtle, so that it turns 120 degrees left (anti-clockwise):

turtle.left(120)

Let's continue by drawing a triangle:

turtle.forward(100)
turtle.left(120)
turtle.forward(100)

Experiment with those commands, and also with turtle.backward() and turtle.right().

Pen control

Try changing the color - for example, turtle.color('blue') - and width of the line - for example, turtle.width(3) - and then drawing again.

You can also move the turtle around without drawing, by lifting up the pen: turtle.up() before moving. To start drawing again, use turtle.down().

The turtle's position

Send your turtle back to its starting-point:

turtle.home()

Get the turtle's current x-y coordinates with:

turtle.pos()

Home is at [0, 0].

To clear the window so we can start anew:

turtle.clear()

Making algorithmic patterns

Using loops, it's possible to build up geometric patterns:

100.times do |steps|
  ['blue', 'red', 'green'].each do |c|
    turtle.color(c)
    turtle.forward(steps)
    turtle.right(30)
  end
end

Let's draw a star shape. We want red lines, filled in with yellow:

turtle.color('red')
turtle.fillcolor('yellow')

turtle.begin_fill()

loop do
  turtle.forward(200)
  turtle.left(170)
  # Check if we are close to home [0, 0]
  pos = turtle.pos()
  break if pos[0].abs < 1 && pos[1].abs < 1
end

turtle.end_fill()

Alternatively, you can use a block for filling:

turtle.color('red', 'yellow')
turtle.fill do
  5.times do
    turtle.forward(200)
    turtle.left(144)
  end
end

Turtle graphics reference

Most of the examples in this section assume you have instantiated a turtle:
turtle = Turtle.new

Turtle motion

forward(distance) / fd(distance)

Move the turtle forward by the specified distance, in the direction the turtle is headed.

turtle.forward(25)

backward(distance) / bk(distance) / back(distance)

Move the turtle backward by distance, opposite to the direction the turtle is headed. Do not change the turtle's heading.

turtle.backward(30)

right(angle) / rt(angle)

Turn turtle right by angle units. (Units are by default degrees).

turtle.right(45)

left(angle) / lt(angle)

Turn turtle left by angle units.

turtle.left(45)

goto(x, y = nil) / setpos(x, y = nil) / setposition(x, y = nil)

Move turtle to an absolute position. If the pen is down, draw line. Do not change the turtle's orientation. You can pass x and y separately, or an array [x, y].

turtle.goto(60, 30)
turtle.goto([20, 80])

setx(x)

Set the turtle's first coordinate to x, leave second coordinate unchanged.

turtle.setx(10)

sety(y)

Set the turtle's second coordinate to y, leave first coordinate unchanged.

turtle.sety(-10)

setheading(to_angle) / seth(to_angle)

Set the orientation of the turtle to to_angle. 0 is East, 90 is North, 180 is West, 270 is South.

turtle.setheading(90)

home()

Move turtle to the origin [0, 0] and set its heading to its start-orientation (0 degrees / East).

turtle.home()

circle(radius, extent = nil, steps = nil)

Draw a circle with given radius. extent determines which part of the circle is drawn (e.g., 180 for a semicircle). steps determines the number of steps to use, which can be used to draw regular polygons.

turtle.circle(50)
turtle.circle(120, 180) # draw a semicircle

dot(size = nil, color = nil)

Draw a circular dot with diameter size, using color.

turtle.dot(20, "blue")

speed(speed = nil)

Set the turtle's speed to an integer value in the range 0..10. 1 is slowest, 10 is fast, 0 is fastest (no animation).

turtle.speed(9)
turtle.speed('fast')

Tell Turtle's state

position() / pos()

Return the turtle's current location [x, y].

turtle.pos() # => [440.0, 0.0]

towards(x, y = nil)

Return the angle between the line from turtle position to position specified by (x, y).

turtle.towards(0, 0)

xcor()

Return the turtle's x coordinate.

ycor()

Return the turtle's y coordinate.

heading()

Return the turtle's current heading.

distance(x, y = nil)

Return the distance from the turtle to (x, y).

Pen control

pendown() / pd() / down()

Pull the pen down -- drawing when moving.

penup() / pu() / up()

Pull the pen up -- no drawing when moving.

pensize(width = nil) / width(width = nil)

Set the line thickness to width or return it.

turtle.pensize(10)

isdown()

Return true if pen is down, false if it's up.

Color control

pencolor(*args)

Return or set the pencolor. Can be a string like "red", a hex string like "#33cc8c", or RGB values.

turtle.pencolor("brown")
turtle.pencolor(50, 193, 143)

fillcolor(*args)

Return or set the fillcolor.

turtle.fillcolor("violet")

color(*args)

Return or set pencolor and fillcolor.

turtle.color("red", "green") # pencolor is red, fillcolor is green

Filling

filling()

Return fillstate (true if filling, false otherwise).

begin_fill()

To be called just before drawing a shape to be filled.

end_fill()

Fill the shape drawn after the last call to begin_fill().

fill(&block)

Fill the shape drawn inside the block.

turtle.color("black", "red")
turtle.fill do
  turtle.circle(80)
end

More drawing control

reset()

Delete the turtle's drawings from the screen, re-center the turtle and set variables to the default values.

clear()

Delete the turtle's drawings from the screen. Do not move turtle.

write(arg, move = false, align = "left", font = ["Arial", 8, "normal"])

Write text - the string representation of arg - at the current turtle position.

turtle.write("Hello World", false, "center", ["Arial", 16, "bold"])

Turtle state

hideturtle() / ht()

Make the turtle invisible. Speeds up drawing.

showturtle() / st()

Make the turtle visible.

isvisible()

Return true if the Turtle is shown, false if it's hidden.

shape(name = nil)

Set turtle shape to shape with given name (e.g. "arrow", "turtle", "circle", "square", "triangle", "classic").

turtle.shape("turtle")

shapesize(stretch_wid = nil, stretch_len = nil, outline = nil)

Scale the turtle's shape.

turtle.shapesize(5, 5, 12)

Screen Methods

You can access the screen object via the turtle to change global properties.

screen = turtle.getscreen()

bgcolor(*args)

Set or return background color of the TurtleScreen.

screen.bgcolor("orange")

bgpic(picname = nil)

Set background image.

screen.bgpic("landscape.png")

clearscreen()

Delete all drawings and all turtles from the TurtleScreen.

tracer(n = nil, delay = nil)

Turn turtle animation on/off and set delay for update drawings. If n is given, only each n-th regular screen update is really performed. Use this to accelerate the drawing of complex graphics.

screen.tracer(8, 25)

update()

Perform a TurtleScreen update. To be used when tracer is turned off.

delay(delay = nil)

Set or return the drawing delay in milliseconds. The longer the drawing delay, the slower the animation.
